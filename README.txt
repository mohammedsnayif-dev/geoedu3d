
# 🌍 GeoEdu 3D

### Free Educational 3D Geological Modeling Application

**Version:** 1.0 (Mobile PWA)  
**Developer:** Mohammed Nayif  
**Origin:** Kurdistan Region of Iraq

## 🪨 About GeoEdu 3D

GeoEdu 3D is a free, interactive educational geological
modeling application developed to help students, teachers,
and geoscience enthusiasts understand geological structures
through 3D visualization.

The application provides accessible tools for exploring
rock formations, geological folds, faults, cross-sections,
and stratigraphy.

## 🚀 Launch the Application

https://mohammedsnayif-dev.github.io/geoedu3d/

GeoEdu 3D runs directly in a web browser.

## ✨ Main Features

- Interactive 3D geological models
- Geological formations and rock layers
- Anticline and syncline modeling
- Normal, reverse, and strike-slip faults
- Geological cross-sections
- Stratigraphic columns
- Lithology patterns
- Interactive geological visualization
- Mobile-friendly Progressive Web App (PWA)

## 🎓 Educational Purpose

GeoEdu 3D is designed for geology students,
petroleum geology students, educators, and beginners.

Its mission is to make geological modeling education
more accessible and interactive.

## 📱 Mobile Installation

### Android
1. Open GeoEdu 3D in Google Chrome.
2. Open the browser menu.
3. Select "Install app" or "Add to Home screen".

### iPhone
1. Open GeoEdu 3D in Safari.
2. Tap the Share button.
3. Select "Add to Home Screen".

## 💻 Technology

GeoEdu 3D uses:

- HTML
- CSS
- JavaScript
- Three.js
- Progressive Web App technology

## 🛠️ Deployment to GitHub Pages

1. Keep all application files and the icons/ folder together.
2. Upload index.html, manifest.webmanifest, sw.js,
   and icons/ to the same GitHub Pages repository folder.
3. Commit changes and wait for deployment.
4. Open the HTTPS GitHub Pages URL.
5. Test the 3D engine and mobile layout on real devices.

The original geological modeling tools and educational
content are contained in index.html.

Offline functionality depends on the app and its external
Three.js library being loaded and cached successfully.

## 🌍 Project Origin

GeoEdu 3D is an independently developed educational
