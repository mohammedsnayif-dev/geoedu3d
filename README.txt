GeoEdu 3D Mobile PWA v1.0

DEPLOY TO GITHUB PAGES:
1. Keep all files and the icons/ folder together.
2. Upload index.html, manifest.webmanifest, sw.js, and icons/ to the SAME folder of your GitHub Pages repository.
3. Commit changes and wait for GitHub Pages deployment.
4. Visit your HTTPS GitHub Pages URL on a phone.
5. Android (Chrome): browser menu > Install app / Add to Home screen.
6. iPhone (Safari): Share > Add to Home Screen.

The original GeoEdu 3D modeling tools and educational content remain in index.html.
Offline mode works after the app and its external Three.js library have been loaded and cached at least once.
Test the 3D engine and mobile layout on real Android and iPhone devices.
